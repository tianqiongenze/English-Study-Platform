# ESP SLO 与错误预算

## SLO 目标
| 指标 | 目标 | 测量方式 |
|---|---|---|
| 可用性 | 99.9% | 成功请求 / 总请求 |
| P95 延迟 | < 500ms | HTTP 请求延迟 |
| 错误率 | < 0.1% | 5xx / 总请求 |
| 并发 | 5000 CCU | WebSocket 连接数 |

## 错误预算
- 月度错误预算 = (1 - 0.999) × 30天 × 24h × 3600s = 259.2s 停机时间
- 周度错误预算 = 59.8s
- 日度错误预算 = 8.64s

## 告警阈值
| 告警 | 条件 | 持续时间 | 严重级别 |
|---|---|---|---|
| 高错误率 | 5xx > 0.1% | 5min | P1 |
| P95 延迟超标 | p95 > 500ms | 5min | P2 |
| 可用性下降 | success_rate < 99.9% | 10min | P1 |
| Pod 重启频繁 | restarts > 3 | 5min | P2 |
| CRDB OOM | restarts > 0 | 立即 | P0 |
| Redis cluster DOWN | cluster_state != ok | 立即 | P0 |

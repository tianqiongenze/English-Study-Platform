# ESP SLO与错误预算

## SLO目标(用户批准)

| 指标 | 目标 | 测量方式 |
|------|------|----------|
| 可用性 | 99.9%(月度) | 成功请求/总请求 |
| P95延迟 | < 500ms | HTTP请求延迟 |
| 错误率 | < 0.1% | 5xx/总请求 |
| 并发 | 5000 CCU | WebSocket连接数 |

## 错误预算

- 月度错误预算 = (1-0.999) × 30天 × 24h × 3600s = **259.2s** 停机时间
- 周度错误预算 = **59.8s**
- 日度错误预算 = **8.64s**

## 告警阈值

| 告警 | 条件 | 持续时间 | 严重级别 |
|------|------|----------|----------|
| 高错误率 | 5xx > 0.1% | 5min | P1 |
| P95延迟超标 | p95 > 500ms | 5min | P2 |
| 可用性下降 | success_rate < 99.9% | 10min | P1 |
| Pod重启频繁 | restarts > 3 | 5min | P2 |
| CRDB OOM | restarts > 0 | 立即 | P0 |
| Redis cluster DOWN | cluster_state != ok | 立即 | P0 |

## 响应时间

| 级别 | 响应时间 | 示例 |
|------|----------|------|
| P0 | 15min | CRDB OOM, Redis DOWN |
| P1 | 1h | 错误率超标, 可用性下降 |
| P2 | 4h | P95延迟超标, Pod重启频繁 |

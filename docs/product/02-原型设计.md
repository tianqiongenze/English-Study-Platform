## 1. 多端信息架构

### 1.1 三端信息架构对照

```
ESP Home-Tutor · 多端信息架构
├── 公共
│   ├── 登录 / 注册
│   │   ├─ Web/H5:账号密码 / 手机验证码 → JWT(RS256, BFF 签发)
│   │   └─ 小程序:wx.login → code2session → 后端换 JWT
│   └── 角色切换(学习者 / 教师)+ 用户菜单
├── 学习者中心 (Learner)
│   ├── 口语陪练 (Speech)  → gateway-go + 数字人 + 口语智能体
│   ├── 写作批改 (Writing) → writing-py + 写作批改智能体
│   ├── 自适应学习 (Learning) → learning-java + 学习路径智能体
│   │   ├── 知识图谱 / 薄弱点
│   │   ├── 今日复习清单(艾宾浩斯)
│   │   └── 动态难度练习
│   └── 我的进度
└── 教师中心 (Teacher)  [Web 全功能 / H5 只读分析 / 小程序不含]
    ├── 教案生成 → teacher-java + 教案智能体
    ├── 班级学情分析 → teacher-java (TiFlash)
    └── 作业评阅 → teacher-java
```

### 3.7 小程序 WebSocket 约束(关键实现约束)
- 微信小程序使用 `wx.connectSocket` / `Taro.connectSocket`,**非原生 WebSocket**;生产环境必须 **wss://** 且域名在小程序后台白名单(需 ICP 备案)。
- 开发期使用微信开发者工具"不校验合法域名"选项,直连 gateway-go NodePort `ws://<node>:30080/ws/speech/{id}`。
- gateway-go 需支持小程序 WS 子协议协商(Sec-WebSocket-Protocol),详见 SDD ADR-13/14。

### 4.1 口语陪练会话(含数字人 + 智能体)
```

 │ 选场景       │ POST /api/sessions(JWT) │ 鉴权     │ Create(Redis)   │
```

## 5. 设计规范
- **配色**:品牌主色教育蓝 `#2D6CDF`,辅色绿(掌握)/橙(薄弱)/红(错误),中性灰背景。
- **字体**:系统无衬线,正文 14-16px,标题 18-24px;H5/小程序正文 15-17px(移动可读性)。
- **反馈**:操作即时 toast;长任务(批改)用骨架屏;错误用红色边框 + 提示。
- **无障碍**:对比度 ≥ AA,按钮可键盘聚焦,图标带 aria-label。
- **响应式**:Web 桌面 ≥1024px 侧栏+内容;H5/小程序 <768 底部 Tab。
- **数字人**:唇形同步延迟 ≤200ms;表情随情绪(emotion-svc)切换;降级为静态头像。
- **智能体**:所有智能体建议以"💡"标识,可被用户采纳/忽略;透明可追溯(显示依据)。

### 6.6 数字人驱动链路
- 前端 `Avatar` 组件订阅 WS `ai_reply` 帧(`data`=base64 TTS 音频 + `emotion` 标签)→ 驱动唇形(WebRTC AnalyserNode / canvas 重绘)与表情切换。
- 情绪标签由 gateway-go 调 emotion-svc `/api/emotion/sense` 得到,附在 `ai_reply` 帧。
- 降级:数字人不可用 → 静态头像 + 文本气泡。
- 三端组件接口统一:`AvatarProps { audioFrame?: string; emotion?: 'happy'|'neutral'|'encouraging'|'sad'; text?: string }`。

### 6.7 智能体编排
四类智能体经各服务编排,LLM 统一 `LlmProvider` 抽象(直连 Anthropic;复用本机 Claude Code 端点;压测 mock)。前端以"💡"标识智能体建议,可采纳/忽略,显示依据。
| 智能体 | 触发端 | 所在服务 |
|---|---|---|
| 口语陪练智能体 | 三端口语页 | gateway-go `dialog.Engine` |
| 写作批改智能体 | 三端写作页 | writing-py `WritingService` |
| 学习路径智能体 | 三端学习页 | learning-java `LearningService` |
| 教案智能体 | Web 教师页 | teacher-java `LessonPlanGenerator` |

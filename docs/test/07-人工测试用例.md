## 1. NodePort 人工测试地址表(核心)

> 单节点下 Mac host 通过 `localhost:<NodePort>` 直连各服务,无需 Host header、无需 port-forward。
> 由 `deploy/k8s/45-httptest-nodeports.yaml` 提供。

| 服务 | NodePort | host 访问 URL | 用途 |
|---|---|---|---|
| gateway-go | 30080 | http://localhost:30080 | 口语场景/会话/WS(/api/scenarios、/api/sessions、/ws/speech) |
| bff-java(REST) | 30009 | http://localhost:30009 | 鉴权 /api/auth/login/register + actuator/health |
| bff-java(edge) | 30010 | http://localhost:30010 | Netty 边缘接入(对外 HTTP) |
| learning-java | 30081 | http://localhost:30081 | 学习路径 /api/learning/* |
| teacher-java | 30083 | http://localhost:30083 | 教师教案 /api/teacher/* |
| writing-py | 30082 | http://localhost:30082 | 写作批改 /api/writing/* |
| emotion-svc | 30084 | http://localhost:30084 | 情绪/可视化 /api/emotion/* |
| writing-coach | 30085 | http://localhost:30085 | 写作增强 /api/writing-coach/*(模板/范文/综合批改/提升方案) |
| frontend-react | 30090 | http://localhost:30090 | Web 前端 nginx 托管(已部署版) |
| nacos | 30048 | http://localhost:30048/nacos | 配置/注册中心控制台 |
| sentinel | 30058 | http://localhost:30058 | 流控控制台 |
| seata | 30071 | http://localhost:30071 | Seata 控制台(TC 30092) |

> 路由说明:
> - **NodePort 直连** = 绕过 Ingress,按服务端口直测(最直观,推荐人工测试)。
> - **Ingress(Host header)** = `curl -H 'Host: esp.example.com' http://localhost/<path>`,由 Traefik 按 path 路由到对应服务,适合测全链路路由(见 §1.2)。
> - **ClusterIP** = `kubectl -n esp-prod exec deploy/<x> -- ...` 集群内测,人工测试不必用。

### 1.1 API 直测清单(逐服务冒烟)

```bash
# gateway:口语场景列表(走 Redis Cluster 缓存)
curl -s http://localhost:30080/api/scenarios | head -c 200

# bff:健康
curl -s http://localhost:30009/actuator/health

# learning:薄弱点(需已建表+种子)
curl -s "http://localhost:30081/api/learning/mastery/weak?user_id=1" | head -c 200

# writing:作文批改(真实 AI 需配 key,默认 Mock 也能出分)
curl -s -X POST http://localhost:30082/api/writing/grade \
  -H 'Content-Type: application/json' \
  -d '{"prompt":"t","essay":"This is good.","exam":"toefl"}' | head -c 300

# writing-coach:写作增强(模板/范文/综合批改/提升方案,调 writing-py + learning)
curl -s http://localhost:30085/api/writing-coach/templates | head -c 200
curl -s -X POST http://localhost:30085/api/writing-coach/plan \
  -H 'Content-Type: application/json' -d '{"user_id":1,"goal":"toefl"}' | head -c 300

# emotion:可视化(需配图像 key)
curl -s -X POST http://localhost:30084/api/emotion/visual \
  -H 'Content-Type: application/json' -d '{"word":"happy","context":"I am happy"}' | head -c 200
```

### 1.2 Ingress 全链路(Host header)

```bash
# 鉴权(bff)+ 学习(learning)+ 写作(writing)经 Traefik 按 path 路由
curl -s -H 'Host: esp.example.com' http://localhost/api/auth/login \
  -X POST -H 'Content-Type: application/json' \
  -d '{"email":"test@test.com","password":"test123"}'
```

## 2. Web 端(frontend-react)测试

### 2.1 两种运行方式

**方式 A:测已部署版(推荐)**
- 直接访问 http://localhost:30090(nginx 托管,已 build 进镜像)
- `/api` 反代由 nginx.conf 配置(指向集群内 Service DNS)

**方式 B:本地 dev 模式(改代码时)**
```bash
cd frontend-react
# 指向集群 NodePort:BFF REST -> 30009,WS -> 30080
VITE_API_TARGET=http://localhost:30009 VITE_WS_TARGET=ws://localhost:30080 npm run dev
# 访问 http://localhost:3000
```

## 8. Go/Rust 微服务功能用例(2026-08-14 补全,覆盖原 P0 外的 8 个服务)

> 原 §1-7 仅覆盖 7 个 P0 服务(bff/learning/teacher/gateway/emotion/writing/writing-coach)。本节补全 8 个 Go/Rust 微服务的功能用例,均为 ClusterIP:80,经 traefik(Host esp.example.com)或直连 NodePort 测。
> NodePort 表:均无独立 NodePort(ClusterIP),走 Ingress 或集群内测。统一入口可走 `frontend-portal`(NodePort 30070,见 17-frontend-portal.yaml)。

### 8.1 API 直测清单(逐服务冒烟,ClusterIP 集群内)

```bash
# 用临时 pod 集群内直连 ClusterIP(绕过 host port-forward)
kubectl -n esp-prod run tmp-probe --rm -i --restart=Never --image=curlimages/curl:8.10.1 -- command -c '

# course-path-go:学习路径生成/解锁
echo "=== course-path /api/path/ ==="
curl -s -m5 http://course-path-go/api/path/ | head -c 200; echo

# listening-go:听力材料列表
echo "=== listening materials ==="
curl -s -m5 "http://listening-go/api/listening/materials?level=A2" | head -c 200; echo

# reading-go:阅读篇章列表
echo "=== reading passages ==="
curl -s -m5 "http://reading-go/api/reading/passages?level=B1" | head -c 200; echo

# gamification-go:积分排行榜
echo "=== gamification leaderboard ==="
curl -s -m5 http://gamification-go/api/gamification/leaderboard | head -c 200; echo

# live-tutor-go:真人导师可约时段
echo "=== tutor availability ==="
curl -s -m5 "http://live-tutor-go/api/tutor/availability?date=2026-08-15" | head -c 200; echo

# media-learn-rs:影视片段列表(注:实际路由 /api/media/*,非 OpenAPI 旧值)
echo "=== media clips ==="
curl -s -m5 http://media-learn-rs/api/media/clips | head -c 200; echo

# pronunciation-rs:发音评分(POST)
echo "=== pronunciation score ==="
curl -s -m5 -X POST http://pronunciation-rs/api/pronunciation/score \
  -H "Content-Type: application/json" \
  -d "{\"text\":\"hello world\",\"audio_ref\":\"mock\"}" | head -c 200; echo

# assessment-rs:测评建会(POST)
echo "=== assessment session ==="
curl -s -m5 -X POST http://assessment-rs/api/assessment/sessions \
  -H "Content-Type: application/json" \
  -d "{\"user_id\":1,\"type\":\"placement\"}" | head -c 200; echo
'
```
